User scenarios

Three workflows, zero manual wiring

Every workflow is a single command. The orchestrator coordinates the agent pipeline, gating each stage on quality checks before moving forward.

Profile architecture

Five orthogonal axes, conflict-free by design

Profiles are organised along five axes — each axis owns specific manifest fields, so profiles never overwrite each other. Mix and match whatever you need.

language exactly 1
Build commands, LSP, formatter, MCP integration.
kotlin-gradle make-generic
framework 0…N
UI framework, platforms, framework-specific forbidden patterns.
compose-multiplatform paper-plugin
host 1…N
Which template tree is rendered, host config file, agent frontmatter format.
claude-code opencode
provider 1 if opencode
Model routing for OpenCode installs (RouterAI, Ollama Cloud, …).
routerai ollama-cloud
capability 0…N
Cross-cutting concerns — security baselines, design principles, full pipelines.
security-baseline solid requirements-pipeline

Living test-cases file

Your control panel for quality

A markdown file is the single source of truth between you and the agent team. Edit it manually — the agents pick up every change on the next /kit-fix.

vault/auth/test-cases/oauth-login-test-cases.md
TC-ID Description Status Notes
TC-01 Successful Google OAuth login redirects to dashboard PASS Verified 2026-05-03
TC-02 Cancelled OAuth flow shows friendly error, no crash PASS
TC-03 Token refresh after expiry keeps session alive FAIL Session drops after 1h — token not refreshed
TC-04 Concurrent login from two devices invalidates older session PEND
TC-05 Login with email containing + sign succeeds FAIL Added manually — crashes with 400 Bad Request
✏️ You edited TC-03 and TC-05 to FAIL, then ran /kit-fix — the agent team handles the rest.
1. You mark failures
Change any row's Status to FAIL. Add a Note with the symptom. No tooling needed — just edit the markdown.
2. Run /kit-fix
@TestRunner scans the file, lists all FAIL/PEND rows, asks which to fix. Pick one, a few, or all.
3. Agents fix & verify
@BugFixer analyzes, fixes, @CodeReviewer checks, @TestRunner re-verifies. Status flips to PASS Verified.
Keeping it current

Update and extend without breaking anything

The kit evolves with your project. Both operations run as AI-driven commands — no manual file merging.

↑

Update the kit

Run /kit-update inside any installed project. The agent reads the changelog, shows you breaking changes, merges new files, and bumps kit_version — your vault and planning files are never touched.

/kit-update
+

Add a profile

Pull in any capability or framework profile by URL — from this repo or a third-party one. The agent validates, deep-merges, and re-renders only the affected files.

/kit-extend https://…/profiles/capability/solid.yaml
✕
